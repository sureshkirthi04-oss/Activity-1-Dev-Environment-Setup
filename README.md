# C/C++ Development Environment Setup

## Setup and Verification

This project demonstrates the setup and verification of a C/C++ development environment using Visual Studio Code and GCC compiler.

### Software Requirements
- Visual Studio Code
- GCC Compiler (MSYS2)
- Windows Operating System

### C Program

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

### Compilation

```bash
gcc hello.c -o hello
```

### Execution

```bash
./hello
```

### Output

Hello, World!

### Project Files
1. README.md – Project documentation.
2. hello.c – C source code.
3. hello.exe – Compiled executable.
4. hello-world-output.png.jpeg – Output screenshot.
